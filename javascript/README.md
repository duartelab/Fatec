# Desafios de JavaScript — Formulários

Dez exercícios de JavaScript com formulários, feitos em um único arquivo, `desafios.html`, só com HTML e JavaScript.

- **Autora:** Raquel S.R. Duarte

## Desafios
1. Contador de caracteres de um comentário (limite de 140)
2. Confirmação de senha, com botão Cadastrar bloqueado até as senhas coincidirem
3. Total do pedido conforme o produto e a quantidade
4. Cadastro de produto com saída em JSON
5. Máscara de telefone `(XX) XXXXX-XXXX`
6. Departamento e funcionário (selects dependentes)
7. Habilidades em etiquetas, com botão de remover
8. Verificação de maioridade pela data de nascimento
9. Selecionar todos os itens
10. Modo escuro salvo no `localStorage`

## Como abrir
Abra `desafios.html` no navegador.
